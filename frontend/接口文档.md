# 南京大学 Passion 街舞社导师课系统 接口文档

Base URL: /api  
认证方式: Authorization: Bearer <token>  
Token ；数据库持久化随机 token。  
角色: user / operator / admin / superadmin

统一响应格式:
```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```
错误示例:
```json
{
  "code": 409,
  "error_code": "409",
  "message": "课程已满"
}
```

分页约定:
- 请求参数: page(>=1), page_size(默认20, 最大100)
- 响应附带:
```json
"meta": { "total": 120, "page": 1, "page_size": 20 }
```
- 常见 code 语义：
  - 200 成功
  - 400 请求参数错误
  - 401 未认证/登录失效
  - 403 权限不足
  - 404 资源不存在
  - 409 业务冲突（如重复预约、名额已满）
  - 500 服务器错误

## 1. 用户认证与用户信息

### 1.1 微信登录
- Method: POST
- URL: /api/user/login
- 权限: 匿名
- 请求:
```json
{ "code": "wx_login_code" }
```
- 成功响应:
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "token": "TOKEN",
    "user": {
      "id": 123,
      "openid": "openid",
      "nickname": "昵称",
      "real_name": null,
      "phone": null,
      "avatar": "url"
    }
  }
}
```
- 失败响应: 400/401/500
- 备注: 首次登录自动创建用户；前端保存 token 并在后续请求携带 Authorization: Bearer TOKEN。

### 1.2 获取当前登录用户信息
- Method: GET
- URL: /api/user/profile
- 权限: user
- 响应:
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 123, 
    "openid": "openid", 
    "nickname": "昵称",
    "real_name": null, 
    "phone": null, 
    "avatar": "url", 
    "status": "active"
  }
}
```
- 失败: 401 登录失效

### 1.3 更新用户信息
- Method: PUT
- URL: /api/user/profile
- 权限: user
- 请求(任意可选字段):
```json
{
   "real_name": "张三", 
   "phone": "13800000000",
   "avatar": "url" 
 }
```
- 响应: 返回更新后的用户
- 校验: 手机号格式、长度限制

## 2. 导师卡 (Cards)

### 2.1 获取当前用户卡片列表
- Method: GET
- URL: /api/user/cards
- 权限: user
- 响应:
```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "id": 1,
      "card_number": "CARD20250001",
      "card_type": "semester",
      "status": "active",
      "start_date": "2025-09-01",
      "end_date": "2026-01-31"
    }
  ]
}
```

### 2.2 管理员发放/绑定卡
- Method: POST
- URL: /api/admin/cards
- 权限: admin+
- 请求:
```json
{
  "user_id": 123,
  "card_type": "semester",   // semester / annual / lifetime
  "start_date": "2025-09-01",
  "card_number": "可选"
}
```
- 响应: 卡片详情
- 备注: card_number 唯一；user_id 可为空表示未绑定

### 2.3 管理员修改卡（激活/失效/延长）
- Method: PUT
- URL: /api/admin/cards/:id
- 权限: admin+
- 请求示例:
```json
{ "status": "inactive", "end_date": "2026-12-31" }
```
- 响应: 更新后的卡片

## 3. 课程 (Courses)

### 3.1 获取周课程列表
- Method: GET
- URL: /api/courses/week?week_start=2025-11-24&dance_type=HipHop&teacher=A
- 权限: 公开 (登录后可携带预约状态)
- 响应:
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "week_start": "2025-11-24",
    "courses": [
      {
        "id": 101,
        "course_date": "2025-11-25",
        "start_time": "19:00",
        "end_time": "20:30",
        "teacher": "导师A",
        "dance_type": "HipHop",
        "capacity": 20,
        "current_participants": 12,
        "status": "published",
        "week_number": 48,
        "reserved": true
      }
    ]
  }
}
```

### 3.2 管理员按周批量发布
- Method: POST
- URL: /api/admin/courses/batch
- 权限: admin+
- 请求:
```json
{
  "week_start": "2025-11-24",
  "courses": [
    {"course_date":"2025-11-24","start_time":"18:00","end_time":"19:00","teacher":"A","dance_type":"Locking","capacity":20},
    {"course_date":"2025-11-24","start_time":"19:00","end_time":"20:00","teacher":"B","dance_type":"Popping","capacity":15}
  ],
  "copy_from_week_start": null
}
```
- 响应: 本周课程列表或批次标识

### 3.2 管理员按周批量发布（更新）
- Method: POST
- URL: /api/courses/batch
- 权限: admin+
- 请求体（JSON 数组）：
```json
[
  {
    "course_date": "2025-12-08",
    "start_time": "19:00",
    "end_time": "21:00",
    "teacher": "Teacher X",
    "dance_type": "HipHop",
    "capacity": 25,
    "week_number": 50
  }
]
```
- 响应示例：
```json
{"code":200,"message":"success","data":{"success":1,"failed":0,"errors":[]}}
```
- 备注：字段校验与类型转换，失败项返回错误列表；后续将加入管理员 JWT 鉴权与重复检测、事务处理。

### 3.3 管理员编辑课程
- Method: PUT
- URL: /api/courses/:id
- 权限: admin+
- 请求示例:
```json
{ "capacity": 25, "status": "cancelled" }
```
- 响应: 更新后的课程

## 4. 预约 (Reservations)

### 4.1 用户预约课程
- Method: POST
- URL: /api/reservations
- 权限: user
- 请求:
```json
{ "course_id": 101 }
```
- 成功响应:
```json
{ "code": 200, "message": "success", "data": { "reservation_id": 1001, "status": "reserved" } }
```
- 失败:
  - 403 无有效卡
  - 409 已满或时间冲突
- 事务逻辑:
  1) 锁课程行 SELECT … FOR UPDATE  
  2) 校验卡有效  
  3) 校验时间冲突  
  4) 插入 reservation, 更新计数  
  5) 提交或回滚

### 4.2 取消预约
- Method: DELETE
- URL: /api/reservations/:id
- 权限: user(本人)/admin+
- 业务: status -> cancelled, 并回退课程计数
- 响应: 成功或失败

### 4.3 获取当前用户预约列表
- Method: GET
- URL: /api/reservations/my?page=1&page_size=20
- 权限: user
- 响应包含课程信息、checkin_status、创建时间、meta

### 4.4 管理员查看某课程预约名单
- Method: GET
- URL: /api/reservations/course/:id
- 权限: admin+
- 响应: 用户列表 + 签到状态

## 8. 认证与校验规则

- Header: Authorization: Bearer <token>
- 登录失效: token 过期或不存在
- 管理员 token: 需携带 role 声明
- 有效卡: status='active' 且 (card_type='lifetime' 或 start_date<=今天<=end_date)
- 时间冲突: 同日期且 NOT (existing.end_time <= new.start_time OR existing.start_time >= new.end_time)
- 课程满员: current_participants < capacity
- 取消限制: 开始前 N 分钟可取消(可配置)
